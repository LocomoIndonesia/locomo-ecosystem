# Locomo Federated Ecosystem

Sistem Operasi Sosial & Ekosistem Layanan Terfederasi **Locomo.ID**.

## 📌 Ringkasan Ekosistem
Ekosistem ini mencakup berbagai modul dan platform terintegrasi:
- **Mandeh.ID**: Gateway identitas warga & wisatawan berbasis token terdesentralisasi.
- **Mandeh.Online**: Portal wisata, reputasi, dan direktori UMKM/layanan publik.
- **Unimart.Group**: Platform SaaS Multi-Tenant Kasir Pintar (POS) & Asisten Bisnis Pintar F&B.
- **PitiCoin.id**: Sistem tokenisasi loyalitas & poin transaksi mikro lokal.
- **Tapak Pandeka & Walikelas.id**: Jaringan kepemudaan dan platform akademik komunitas.
- **Locomo Agent OS**: Lapisan kognitif otonom untuk tata kelola dan orkestrasi sistem.

## 🛠️ Infrastruktur & Deployment
- **Arsitektur**: Docker-First Multi-Container
- **Stack**: Laravel 11/13, Python FastAPI, PostgreSQL (pgvector), Ollama AI Engine
